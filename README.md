# k-shell

A lightweight, custom Unix shell written in C.
Designed to implement core operating system concepts: process creation, execution, and signal handling.

## 📂 Project Structure
- `src/`: Contains the source code (e.g., `main.c`).
- `include/`: Contains header files (future use).
- `Makefile`: Build script.

## 🛠️ Usage

### 1. Compile
